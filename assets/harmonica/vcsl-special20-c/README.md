# VCSL C diatonic harmonica samples

These nine files are a range-limited subset of the Versilian Community Sample
Library (VCSL) C diatonic harmonica normal sustains.

- Source: [sgossner/VCSL](https://github.com/sgossner/VCSL)
- Source directory: `Aerophones/Free Aerophones/Harmonica-Hohner-Special20-C`
- Retrieved: 2026-09-02 from the repository's `master` branch
- Publisher: Versilian Studios LLC
- License: Creative Commons CC0 1.0 Universal public-domain dedication
- License text: [VCSL LICENSE](https://github.com/sgossner/VCSL/blob/master/LICENSE)

SonicViz selected nine normal-sustain C, E, and G anchors mapped to MIDI 60, 64,
72, 76, 79, 84, 88, 91, and 96. Each mono source was trimmed to at most 1.35
seconds, resampled to 32 kHz, and losslessly encoded as FLAC with FFmpeg. The
files total 993,514 bytes and cover MIDI 60-96 with at most four semitones of
pitch shifting. Source-specific level differences are compensated at runtime,
so the FLAC waveforms retain better compression than pre-normalized copies.

Soft, vibrato, and release recordings are omitted. These anchors do not claim
distinct draw, bend, overblow, or overdraw timbres. Product names identify the
upstream source only; no trademark license, endorsement, or affiliation is
claimed.
