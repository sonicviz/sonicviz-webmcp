# Upright Piano KW samples

These samples are a range-limited subset of the FreePats Upright Piano KW
small sound bank, recorded from a Kawai upright piano by Gonzalo and Roberto.

- Source: [FreePats Upright Piano KW](https://freepats.zenvoid.org/Piano/acoustic-grand-piano.html#UprightKW)
- Sound bank version: 2019-07-03
- License: Creative Commons CC0 1.0 Universal public domain dedication
- License text: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/)

The 12 included FLAC files total 1,405,512 bytes and cover the MIDI 37-76 range
used by SonicViz backing chord voicings.
